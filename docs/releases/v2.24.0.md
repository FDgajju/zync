# Release Notes - Zync v2.24.0

**Release date:** 2026-08-18

---

## What's New

Zync v2.24.0 adds a notification center, safer password storage on host create, and round-trip tunnel support in connection export/import files.

You get a corner-following toast stack plus a bell inbox for longer-lived notices, a **Save to Vault** path when creating password-auth hosts, and `.zync` files that can carry port forwards with your hosts. Plugins can raise notifications through the existing worker bridge.

Highlights:

* Notification center with bell inbox, DND, sound, and corner position prefs
* Public `notify.*` API for app features and a plugin `api:ui:notify` bridge with action RPC
* **Save to Vault** when creating a password-auth host (`ssh-password` + `authRef`)
* Import tunnels from Zync connection files; export includes tunnels (orphans kept on full export)
* Stronger notification a11y (modal backdrop, keyboard position radiogroup)

Compare: [v2.23.1...v2.24.0](https://github.com/zync-sh/zync/compare/v2.23.1...v2.24.0)

## Added

* **Import tunnels with connection files** — Zync JSON/`.zync` imports can include a `tunnels` array; import applies those forwards with the host so dummy and full workspace files work in one step. ([cb1cdc6](https://github.com/zync-sh/zync/commit/cb1cdc6), [af92092](https://github.com/zync-sh/zync/commit/af92092))
* **Export tunnels in `.zync` files** — Full connection export writes saved tunnels (as stopped) into the `tunnels` array; scoped export includes only tunnels for the selected hosts. ([af92092](https://github.com/zync-sh/zync/commit/af92092))
* **Password → Vault on host create** — Password auth offers **On this host** or **Save to Vault**; the vault path creates an `ssh-password` credential and links the host via `authRef` (no plaintext password on the host). ([060f1c2](https://github.com/zync-sh/zync/commit/060f1c2))
* **Notification center** — Modular notification package with public `notify.*` API. Toasts and the bell follow the chosen corner. Short-lived success/info stay on-screen only; errors/warnings and sticky/actionable items go to the inbox (localStorage, max 50, auto-prune after 7 days). Inbox: Clear all, hover/focus pause, gear prefs (position, DND, sound), in-session actions. ([fa72d25](https://github.com/zync-sh/zync/commit/fa72d25), [af92092](https://github.com/zync-sh/zync/commit/af92092))
* **Plugin notify bridge** — Plugins can emit `api:ui:notify` and receive action click results over the existing worker RPC (namespaced action ids, concurrent in-flight lock). ([cc51d57](https://github.com/zync-sh/zync/commit/cc51d57))
* **Notifications architecture docs** — Canonical `docs/NOTIFICATIONS.md` for module layout, history policy, and the plugin bridge. ([fa72d25](https://github.com/zync-sh/zync/commit/fa72d25))

---

## Changed

* **Connection form password storage** — Segmented **On this host** / **Save to Vault** choice when creating a password-auth host (vault must be unlocked for the vault path). ([060f1c2](https://github.com/zync-sh/zync/commit/060f1c2))
* **Toast enter animation** — Corner-aware fade/slide uses project CSS instead of missing animate utilities. ([af92092](https://github.com/zync-sh/zync/commit/af92092))

---

## Fixed

* **Full export keeps orphan tunnels** — Unscoped `.zync` export no longer drops tunnels whose host is missing from the connection list; filtering applies only to scoped export. ([af92092](https://github.com/zync-sh/zync/commit/af92092))
* **tunnels.json load errors on export** — Missing file still exports empty tunnels; read/parse failures surface instead of silently exporting no tunnels. ([af92092](https://github.com/zync-sh/zync/commit/af92092))
* **Partial tunnel import** — A single tunnel save failure no longer aborts the whole import; connections stay saved and a warning toast reports how many tunnels failed. ([af92092](https://github.com/zync-sh/zync/commit/af92092))
* **Notification duration guards** — `NaN`, negative, and non-finite custom durations fall back to type defaults so auto-hide timers stay valid. ([af92092](https://github.com/zync-sh/zync/commit/af92092))
* **Notification center a11y** — Backdrop under the modal, position control as a radiogroup with roving tabindex and arrow/Home/End keys, and a focus trap that respects non-tab stops. ([af92092](https://github.com/zync-sh/zync/commit/af92092))

## Quick Check After Upgrade

1. **Notification bell** — Trigger an error or warning toast, open the bell, confirm it appears in the inbox, then use Clear all.
2. **Toast corner** — Open notification gear prefs, change position (try keyboard arrows on the radiogroup), and confirm toasts and the bell follow that corner.
3. **Password → Vault** — Create a new password host, choose **Save to Vault** (vault unlocked), save, and confirm the host has vault auth rather than a stored plaintext password.
4. **Tunnel import** — Import a `.zync` file that includes tunnels; confirm hosts and tunnels appear, and that a bad tunnel does not undo imported hosts.
5. **Tunnel export** — Export all connections to `.zync` and confirm the file includes a `tunnels` array (stopped); export a subset and confirm only related tunnels are included.
